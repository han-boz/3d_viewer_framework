实验 1 的功能实现，在源文件：plugins/exp1_plugin_color.py

- 插件标识：color_control（在 plugin_config.yaml 中启用）
- 插件名称：color_control
- 功能描述：实验1：HSV/RGB变换与3D色彩实体
- UI 形态：一个可滚动的右侧控制面板 + 若干直接加入 3D 视口的实体
---
实现功能如下：
1. 用 3D 实体展示颜色（渐变立方体、纯色三角形）；
2. 用 HSV 和 RGB 两组参数修改同一个颜色，任意一侧改动，另一侧与 3D 场景实时同步；
3. 把当前颜色应用到真实 OBJ 模型上，完成"给 3D 模型填色"。
面板自上而下分为 4 个区：视口显示内容选择 → HSV 控制区 → RGB 控制区 → 立方体材质与预设色彩。

实验 2 进阶任务的两个插件
------------------------------------------------------------
1) plugins/plugin_texture_mipmap.py   插件标识：texture_mipmap
   - 功能描述：把同一张纹理按 3 种采样方式（GL_NEAREST / GL_LINEAR /
     GL_LINEAR_MIPMAP_LINEAR）贴到当前模型，并支持各向异性过滤、
     重复平铺、平面/圆柱/球面 UV 投影；
   - 勾选“显示 Mipmap 对比地面”后，会把同一张纹理平铺 12x12 铺在地上，
     远处纹理被强烈缩小，4/3 种采样方式的差异一眼可见；
   - UI 形态：右侧控制面板（纹理下拉框 + 投影/采样下拉框 + 各向异性滑块）。

2) plugins/plugin_env_mapping.py      插件标识：environment_mapping
   - 功能描述：环境映射。用 data/texture/skybox/*.jpg 的 6 个面构造 cubemap 做
     全景天空盒（vtkSkybox）；再把 6 个面重采样成等距柱状（lat-long）环境图，
     作为基于图像的光照（IBL）环境贴图，让金属反射球与反射立方体
     （PBR：metallic=1, roughness~0.03）反射环境；缺少素材时自动生成程序化天空。
     注意：IBL 特意用等距柱状图而不是 cubemap，因为 VTK 只能从 2D 图计算球谐，
     用 cubemap 会打印 "Cannot compute spherical harmonics of a cubemap" 警告
     （那只是 WARN，画面仍正常，但不是错误也不需要理会）。
   - UI 形态：右侧控制面板：天空盒/球/立方体显隐、金属度/粗糙度滑块、
     “当前模型也反射环境（PBR）”开关（勾选后把加载的 OBJ 本身也变成金属反射材质，
     取消勾选会还原原来的材质）、重新载入天空盒。

实验 3 的两个插件（光照与材质）
------------------------------------------------------------
1) plugins/exp3_plugin_lighting.py     插件标识：exp3_lighting
   - 功能描述：实验三编程任务2。把任务1的 3x4 共 12 种光照/材质组合
     （无环境光/有环境光/有颜色的环境光 x 仅漫反射/+低高光/+很亮高光/+自发光）
     套到真实 OBJ 模型上；每加载一个模型自动追加一个对比样例，按 4 个一行排列；
     面板可调灯光位置、颜色、强度、高光指数，也可关闭光照查看基础色。
   - UI 形态：右侧面板（多模型开关、12 预设下拉框、光位/光色/强度/高光滑块）。

2) plugins/exp3_plugin_material.py     插件标识：exp3_material
   - 功能描述：实验三进阶要求。提供基于 PBR 的真实材质库（黄金/抛光钢/铜/木质/
     花岗岩/砖石/陶瓷/塑料/橡胶/水面玻璃），按模型名自动匹配材质，并可一键生成
     5 个模型的材质对比示例。金属需要环境反射才像金属：插件会自动生成程序化天空
     作为 IBL 来源；若“环境映射”插件已启用，则直接复用它的全景天空盒。
   - UI 形态：右侧面板（材质下拉框、自动匹配开关、示例场景按钮、金属度/粗糙度滑块）。

内核（core/viewer_3d.py）本次改动：多模型 + 相机/坐标轴/面板
------------------------------------------------------------
1. 多模型：点 OBJ 改为“追加”到场景，不再清空已有模型；重复点同一个模型只切换选中。
   右侧新增“场景 / 模型”面板：模型列表、X/Y/Z 位置微调、自动排列、删除选中、
   清空、适配视图。
2. 相机：适配只按“模型包围盒”计算（天空盒/对比平面等大物体不会再让模型显得很小）；
   “视图”菜单新增 适配全部(F) / 正视(1) / 俯视(2) / 等轴测(3) / 重置视角(R)。
3. 坐标轴：从“跟着模型包围盒摆放的 vtkAxesActor”改成左下角常驻的
   vtkOrientationMarkerWidget，不再遮挡模型、也不会被天空盒带偏。
4. 右侧面板：插件面板放进 QScrollArea，按插件分组且可勾选折叠，插件再多也不会挤爆。
5. 模型加载自动做几何预处理：补点法线（否则高光不出现）、居中、统一尺寸、
   自动摆正（这些 OBJ 多为 Z 轴朝上）；后两项可在“视图”菜单里关闭。
6. 新增地面参考网格，便于判断朝向；可在“视图”菜单里关闭。
7. 交互：轨道球旋转灵敏度调低（MotionFactor 0.6），更容易摆到想要的角度。

默认关闭的功能（避免一开就干扰观感）：
  - 环境映射插件：反射球 / 反射立方体（天空盒仍默认开启）
  - Mipmap 插件的“对比地面”
  - 光照预设插件的“加载模型时自动套用预设”
  - 真实材质插件的“自动匹配”（需要时手动点“应用”）

8. 视口点选：在 3D 视口里单击某个模型即可选中它（等价于在“场景 / 模型”列表里点选），
   选中后模型外会出现橙色包围盒，位置微调/自动排列会同步跟随；
   拖动旋转不会误触发选中，点空白处不改变选中状态。

实验四 进阶：查看器里的光线追踪与凹凸映射
------------------------------------------------------------
1. 光线追踪预览（插件 exp4_raytrace）
   - 把场景里所有模型转成三角形，在 CPU 上建一棵 BVH，节点和三角形一起上传到纹理缓冲，
     片元着色器里遍历 BVH 求交（Möller–Trumbore）。
   - 场景是一个封闭房间：左红墙、右绿墙、白后墙、石板地面、天花板上一块矩形面光源，
     天花板中间那块亮的就是灯；软阴影是在这块矩形上取若干点算出来的。
   - 面板参数：
       材质（漫反射 / 镜面 / 玻璃 / 金属）、反射次数 0~3、软阴影开关、
       阴影采样 4/8/16/32、超采样 1x/2x、光源强度、曝光、视场角。
   - 视角不另外做，直接用框架已有的“视图”菜单：适配全部 / 正视 / 俯视 / 等轴测 /
     重置视角（快捷键 F / 1 / 2 / 3 / R），光追画面会跟着一起变。
   - 选中和移动也复用框架的场景面板：位置微调框、自动排列、删除、清空都会即时反映到
     光追画面；反过来在光追画面里单击模型也会选中列表对应的行（橙色高亮），
     再用 WASD 平移、Q/E 升降，位置同样写回查看器里的模型。
   - 拖动旋转速率约 0.26 度/像素，滚轮缩放；拖动时自动降成 1x 超采样。
   - 加了 BVH 之后，6 万面的飞机（抽稀到 6 千多面）每帧约 20 ms（16 采样软阴影），
     上一版是逐三角形遍历，这种模型必然卡死。
   - 预览用的是独立的 OpenGL 上下文（QOpenGLWidget），不影响 VTK 那边的渲染状态。

2. 凹凸映射（插件 exp4_bump）
   - 用一个程序化三维高度场（几组不同方向的正弦叠加）求梯度，把梯度里垂直于法线的
     分量加到法线上再归一化：几何不动，靠光照表现凹凸。
   - 低模会先做一次线性细分再扰动，细节更明显。
   - 面板里可调凹凸强度、细节尺度，按钮有“应用到选中 / 应用到全部 / 恢复原状”，
     另有“加载模型时自动应用”（默认关闭）。

3. 启用方法
   在 plugin_config.yaml 的 active_plugins 里加上：
       - exp4_raytrace
       - exp4_bump
